# Network Benchmarks

This module contains non-published benchmark tooling for established transport channels.

The current runner targets RakNet established-channel bandwidth, latency, fanout, fairness, disappearing-client, batched game-traffic, and impaired-network matrix runs. See [`docs/benchmarking.md`](docs/benchmarking.md) for usage, [`docs/baseline-status.md`](docs/baseline-status.md) for the current baseline handoff state, [`baselines/zulubox-netns-100c-20260819/RESULTS.md`](baselines/zulubox-netns-100c-20260819/RESULTS.md) for the current single-host resilience baseline and results, [`docs/netns-autonomous-goal.md`](docs/netns-autonomous-goal.md) for the restricted autonomous zulubox launcher, [`docs/baseline-matrix.md`](docs/baseline-matrix.md) for the recurring baseline plan, [`docs/production-usage-evidence.md`](docs/production-usage-evidence.md) for source evidence behind the synthetic, [`docs/lab-baseline-runbook.md`](docs/lab-baseline-runbook.md) for lab baseline capture, and [`docs/teamziax-vm-bench.md`](docs/teamziax-vm-bench.md) for optional TeamZiax VM/eBPF companion evidence.

Use `scripts/capture-production-evidence.sh` to record private-safe source checkout availability and revisions behind the synthetic matrix, `scripts/run-baseline-matrix.sh` to produce recurring suite artifacts, `scripts/prepare-lab-baseline-handoff.sh` to generate the full perfect-network plus impairment lab handoff package, `scripts/plan-lab-baseline.sh` to generate a coordinated remote lab baseline plan, `scripts/plan-lab-impairment.sh` to generate remote lab plans under host-level `tc netem` profiles, `scripts/summarize-lab-impairment.sh` to package a multi-profile impairment campaign summary, `scripts/promote-lab-impairment.sh` to package a validated impairment campaign as a durable baseline, `scripts/check-baseline-readiness.sh` to verify promoted lab and impairment packages are ready as a baseline of record, `scripts/compare-lab-impairment.sh` to compare two impairment campaigns, `scripts/validate-lab-baseline.sh` to enforce baseline-of-record acceptance checks, `scripts/promote-lab-baseline.sh` to package a validated lab run as the durable comparison baseline, `scripts/select-stable-bandwidth.sh` to select the highest stable bandwidth-curve point, `scripts/plan-remote-worker-curve.sh` to generate coordinated remote server/receiver bandwidth-curve commands, `scripts/plan-remote-contention.sh` to generate coordinated fanout, fairness, and disappearance campaigns, `scripts/run-netns-pilot-campaign.sh` to orchestrate the six-profile single-host resilience campaign, `scripts/run-netns-worker-smoke.sh` to run or dry-run one namespace/veth worker case with qdisc outside the JVM, `scripts/run-impairment-matrix.sh` to repeat local suite runs under controlled `tc netem` profiles, `scripts/merge-worker-results.sh` to combine remote server/receiver worker artifacts, and `scripts/compare-baseline-suite.sh` to compare a candidate run against a saved baseline.
