# Network Benchmarks

This module contains non-published benchmark tooling for established transport channels.

The current runner targets RakNet established-channel bandwidth, latency, fanout, fairness, disappearing-client, batched game-traffic, and impaired-network matrix runs. See [`docs/benchmarking.md`](docs/benchmarking.md) for usage, [`docs/baseline-matrix.md`](docs/baseline-matrix.md) for the recurring baseline plan, [`docs/production-usage-evidence.md`](docs/production-usage-evidence.md) for source evidence behind the synthetic, and [`docs/lab-baseline-runbook.md`](docs/lab-baseline-runbook.md) for lab baseline capture.

Use `scripts/run-baseline-matrix.sh` to produce recurring suite artifacts, `scripts/plan-lab-baseline.sh` to generate a coordinated remote lab baseline plan, `scripts/validate-lab-baseline.sh` to enforce baseline-of-record acceptance checks, `scripts/select-stable-bandwidth.sh` to select the highest stable bandwidth-curve point, `scripts/plan-remote-worker-curve.sh` to generate coordinated remote server/receiver bandwidth-curve commands, `scripts/plan-remote-contention.sh` to generate coordinated fanout, fairness, and disappearance campaigns, `scripts/run-impairment-matrix.sh` to repeat that suite under controlled `tc netem` profiles, `scripts/merge-worker-results.sh` to combine remote server/receiver worker artifacts, and `scripts/compare-baseline-suite.sh` to compare a candidate run against a saved baseline.
